\section{Menger's Theorem}

\begin{theorem}[Menger's Theorem]
Let $G$ be a finite undirected graph and $A$ and $B$ two disjoint subsets of vertices. Then the minimum number of vertices that need to be removed to disconnect $A$ from $B$ is equal to the maximum number of vertex-disjoint paths from $A$ to $B$.
\end{theorem}

\begin{proof}
On a graph $G$,  define $n(G)$ as the number of vertex-disjoint paths between $A$ and $B$, and the minimum cut as $m(G)$.

\paragraph{$m \geq n$:} If we have $N = n(G)$ vertex-disjoint paths and we remove $M < n(G)$ of these vertices, $A$ and $B$ must still be connected through at least one path since no paths can share a vertex.

\paragraph{$n \geq m$:}  For any graph $G = (V,E)$, we prove by induction on induced subgraphs of size $k$ (remove all but $k$ nodes). 

Base Case: $k = 0, 1$ are meaningless, with no paths available.  So remove all but 2 vertices from $G$.  If they are connected, $m(G)= n(G) = 1$.  If not, $m(G) = n(G) = 0$.  The condition holds.

Inductive Case: Say for any induced subgraph $G^* = (V^*, E^*)$ of $G$, where $|V^*| = k -1, n(G*) \geq m(G*)$. 

If adding a node $v$ (and its edges incident to $V^*$) back into $G^*$ does not increase the number of vertex-disjoint paths, then our condition holds, since removing $v$ (adding it to the cut set) doesn't change $n(G)$ or $m(G)$. 

If doing so \emph{does} increase the number of vertex-disjoint paths, then it can do so only by one: Cutting $v$ yields $G^*$, where the condition holds, and adding $v$ may increase the cut set by one, but can only add one more vertex-disjoint path to $G*$ (informally, you can't use $v$ more than once).
\end{proof}

Therefore $m(G) = n(G)$.



\section{K\"onig's Theorem}

\begin{theorem}[K\"onig's Theorem]
In a bipartite graph, the size of the maximum matching equals the size of the minimum vertex cover (a set of nodes that together touch every edge).
\end{theorem}

\begin{proof}
Assume we have nodes $\{a_i\}$ in one independent set and $\{b_i\}$ in the other independent set of the bipartite graph.

Relabel them so our maximum matching is $(a_1, b_1) \ldots (a_m, b_m)$. This means there are sets of nodes $\{a_{m+i} \}$ ($i > 0$) that only connect to $b_1 \ldots b_m$ and nodes $\{b_{m+i}\}$ ($i > 0$) that only connect to $a_1 \ldots a_m$.

If some $a_{m+j}, j > 0$ connects to $b_i$, $1 \leq i \leq m$, then no $b_{m+k}$, $k > 0$ can connect to $a_i$, since then we would have a bigger matching by removing $(a_i, b_i)$ and adding $(a_{m+j}, b_i)$ and $(a_i, b_{m+k})$, a contradiction of our assumptions.

Therefore, for every node in the $a$-component outside the matching, add to the cover any adjacent $b_i$ in the matching (and vice versa for every $b$ node outside the matching).  And there can be no nodes in the $b$-component outside the matching connecting to $a_i$, so only one of $a_i, b_i$ will be selected.  If $a_i$ and $b_i$ have no adjacencies outside the matching, or have not been selected after all the non-matched nodes are covered, then select either one for the cover.  Therefore, we will have exactly one node in the cover for every edge in the matching.

This vertex cover covers all nodes outside the original matching and clearly covers all the nodes $a_1 \ldots a_m, b_1 \ldots b_m$ too.  It is the minimum as any node set smaller than size $m$ cannot cover the nodes in the matching.

\end{proof}

\section{Brooks's Theorem}
\begin{theorem}[Brooks]If a graph $G$ is not a clique and not an odd cycle and has maximum degree $d$, it can be properly colored with $d$ colors.
\end{theorem}


First, some lemmas.  Call graphs which are not themselves odd cycles or complete graphs \emph{allowed graphs}.

\begin{lemma}[Augmented odd cycle] If an allowed graph $G$ consists of an odd cycle $C_n$ plus an additional node $v$, it is colorable with maximum degree = $d$ colors.

\textit{Proof}: $G - v = C_n$ is colorable in three colors, an alternating chain of $\frac{n}{2}$ red, blue pairs, plus a final green node.  Since $G$ is an allowed graph, $v$ is connected to $C_n$, and therefore some node in $C_n$ has degree 3.

If $deg(v) \geq 4$, color $v$ yellow, and $\chi(G) \leq 4 \leq d$.  If $deg(v) \leq 2$, a color is clearly available for $v$, so $\chi(G) = 3 = d$.  If $deg(v) = 3$, we consider first $n = 3$.  This is disallowed since $G$ would be a complete graph.  Then since $n \geq 4$, there is a node unconnected to $v$.  Rotate the colors of $C_n$ so this one is green and color $v$ green. Then $\chi(G) = 3 = d$.
\end{lemma}

\begin{lemma}[Augmented complete graph] If an allowed graph $G$ consists of a complete graph $K_n$ plus an additional node $v$, it is colorable with maximum degree $d = n$ colors.

\textit{Proof}: $K_n$ is clearly colorable in $n$ colors.  Since $G = (V, E) $ is an allowed graph, $0 < deg(v)< n$, and $v$ is connected to $K_n$ in $G$.  This means some node in $K_n$ must have degree $n$.  Additionally, since $G$ is an allowed graph, there must be some node $w, (v,w) \notin E$ with degree = $n-1$.  Color $v$ the same as $w$.  The graph is colorable in $n$ colors, with max degree $n$.

\end{lemma}

\textbf{Proof of Brooks's theorem}:

\emph{Note}: We assume this is a connected graph; if it's a disconnected graph, then the maximum degree of any component will be less than or equal to that of the graph, and we can color each component separately by the procedure below.  We also ignore the degenerate graph of a set of isolated nodes.

We will take any allowed $G$ and proceed by induction on induced subgraphs $G^*=(V^*, E^*)$ of $G$. 

Base Case: $|G^*| = 2$: If connected, the graph is a single pair, a clique of size 2, colorable with two colors.

Inductive Case: Assume for all induced subgraphs of $G^*$ of $G = (V,E)$, the proposition holds and $G$ is not an odd cycle or a complete graph and has max degree $d(G)$.

Remove a node $v$ of lowest degree in $G$.  By inductive hypothesis the induced graph $G^* = G - v$, with max degree $d(G^*) \leq d(G)$, is colorable in $d := d(G^*)$ colors.



Also, we assume $d \geq 3$, since otherwise we are done:
\begin{itemize}
\item If $d = 1$,  we have a set of pairs. If $deg(v)$ = 1, $G$ is 2-colorable.  If $deg(v) = 2$, and it is connected to two nodes in a pair, we have a disallowed component of graph $G$.  If  $deg(v) = 2$ and it is connected to two different pairs, that path is two-colorable.  If $deg(v) \geq 3$, color the pairs red-blue and $v$ green.
\item if $d = 2$, and does not include an odd cycle component (handled below), then including a connected $v$ brings max degree of $G$ to at least 3.  Color the even cycles red-blue and $v$ green.
\end{itemize}

Let's also treat easy cases of the induction:

\begin{itemize} 
\item If any induced graph component is a cycle, then the cycle plus v is colorable in 3 colors by the Augmented Odd Cycle lemma or the argument above for $d=2$ (even cycle).  Since $d(G) \geq 3$, this component is covered.
\item  If any induced graph component is a complete graph, then adding $v$ makes it colorable within bounds by the Augmented Complete Graph lemma.  This component is covered.
\item If the maximum degree $d(G^*)$  greater than $deg(v)$, color the induced graph with $d(G^*)$ colors, and there will be at least one left for $v$.
\end{itemize}

Because of the last case, we assume every node in $G*$ has degree at most $deg(v)+1$.

We will illustrate this with $d(G^*) = 3$ (thus $d(G) \leq 4$) and then argue this generalizes to $d(G^*) >  3$.

Include $v$, uncolored, back into the graph $G^*$ as shown:

If $d(G^*) = 4$, we ignore the presumed 'yellow' node connected to $v$ for now (see argument for 'only three colors matter' at the end).

Our goal is to change the number of colors among $\{A, B, C\}$ to less than three.  If that is the case,then $v$ has a free one to select and we're done.

More assumptions:
\begin{itemize}
\item If two of $v$'s neighbors share a color already, then we're done.  Therefore, assume $v$'s neighbors $A$, $B$, and $C$ are colored red, green, and blue, respectively.
\item (*) We show paths between A and C (ignoring D and E for the moment), A and B, and B and C, possibly just a single edge.  They cannot all be single edges, however.  If so, $G = \{A,B,C,V\}$ was a complete subgraph $K_4$.  If disconnected from the rest of the graph, we have a disallowed condition.  If one of these nodes shares an edge outside of this set with some node $w$, then the max degree of $G^*$ is 4 and $v$ can be colored yellow.  So at least one of the three paths has more than one edge (and since alternating colors, must have at least three edges).  Here, without loss of generality, we make it the red-blue path from A to C.  (Note: if $deg(v) = 4$, the same logic applies: there must be a selection of A, B, and C such that two of them are not directly connected.)
\item If there is not an alternating red-blue path from A to C, then switch red and blue along that path and and transitive neighbors.  The graph will still be valid, with A and C both blue.  Color $v$ red.
\item The same logic applies for red-green paths between A and B, and blue-green paths between B and C.
\item So assume there are these three alternating color paths as shown in the figure.

\end{itemize}

If we can flip exactly one endpoint of any of these three paths  $(A,B), (B,C), (A,C)$, we can color $v$ freely.

We introduce another other lemma to help us do our flipping:

\begin{lemma}[Splitting Lemma]
If an alternating color path encounters a node where two successive (yet unflipped) nodes share a color, then then transitive chain starting from the beginning to this point can be flipped.
\end{lemma}
\textit{Proof}:  Refer to the figure.  If in, say a red-blue chain, $w$ is transformed to red, $x$ has been transformed to blue, and $y, z$ are both green, the chain must stop.  If $deg(x) = 3$, it can stay blue while not violating color constraints.  If $x$ is adjacent to an additional blue node, color $x$ yellow since $deg(x) = 4$.
if $y$ and $z$ are both blue,  there is at least one other color to change x to. 
If there is an additional node connected to $x$ and it is 'yellow' (fourth color), the above arguments don't change.  If it is not 'yellow', color $x$ yellow.

In particular, this means that if chains of two colors SPLIT into child chains, the original chain can be flipped up to the point of intersection.


\begin{corollary}[No crossing Lemma]
If two alternating chains cross, they are both flippable at the point of intersection.
\end{corollary}
Similarly to the splitting lemma, this means there are four nodes adjacent to the point of intersection, and therefore at least one color unrepresented in the neighbor set, and the intersection can be colored with one of these.

\end{lemma}

\section{Dirac's Theorem}

\begin{theorem}[Dirac] An $n$-node graph in which each node has degree at least $\frac{n}{2}$ must have a Hamiltonian cycle.
\end{theorem}

First, some lemmas: 

\begin{lemma}[Minimum cycle length] If a graph has nodes all of degree $d \geq 2$,  there exists a cycle within it of length at least $d+1$.
\end{lemma}
\textit{Proof}: A greedy algorithm suffices here.  Select any starting node $v$.  Define the "seen" node list $L$as $\{v\}$ and head node $h$ as $v$.  $N(h)$ is a function defined as the neighbor set of some node $h$.
\begin{enumerate}
\item If $N(h) \subseteq L$, pick the earliest node in the list $e$.  Then the cycle is the slice of $L$ between $e$ and $h$, with $h$ connecting to $e$ at the end.  Because $h$ has degree $\geq d$, $e$ must be at least $d$ nodes back in the list, making the cycle length at least $d+1$.
\item Else append $h$ to $L$ and set $h$ to one of its neighbors not in $L$.
\end{enumerate}

Suppose there is a graph of $G$ of even node count $n > 4$.

There must be a cycle of size $s$ at least $\frac{n}{2} + 1$ by the Minimum cycle length lemma.  Call this component $C$ and the complement $D := G - C$.

\begin{lemma}{Crowded neighbors principle}: If there are $n$ nodes in a cycle, selecting $\lfloor\frac{n}{2}\rfloor + 1$ of them must yield at least two neighboring nodes. 
\end{lemma}
\textit(Proof): Selected nodes cannot outnumber unselected nodes since every selected node must be followed by an unselected one in a cycle without neighbors being selected.

For Dirac's theorem, we first dispatch with small  node counts:


\begin{itemize}
\item This is meaningless for $n \in {1,2}$.  No cycles are possible.
\item This is clear for $n = 3$: a triangle.
\item For $n = 4$, connected nodes $a$ and $b$ must be connected to $c$ and $d$ respectively (blue edges in figure), or both to some $c$ (red edges).
 \begin{itemize}
 \item If the first (blue) case, if $c$ is connected to $d$, we have a 4-cycle.  If $c$ is connected to $b$, then $d$ must be connected to $a$ or $c$, both yielding cycles.
 \item if the second (red) case, $d$ is connected to two of $\{a,b,c\}$, creating a 4-cycle.
\end{itemize}
\end{itemize}

\section{Lovasz's Theorem}

\begin{definition}[Perfect Graph]
A weakly perfect graph $G$ has a chromatic number $\chi(G)$ (the number of colors required for a vertex coloring) equal to its clique number $\omega(G)$ (the size of its largest fully-connected subgraph or \emph{clique}).  A refinement of this, a strongly perfect graph $G$, has this property for every induced subgraph $G^* \subset G$.
\end{definition}

\begin{theorem}[Lovasz]
The complement of any perfect graph is perfect.
\end{theorem}

Let's start with a seemingly smaller theorem: A cobipartite graph (complement of a bipartite graph) is perfect.  Since a bipartite graph is clearly perfect (chromatic number of two, clique number of two), showing this proves Lovasz's theorem for a subset of graphs.

In a cobipartite graph, there are two cliques, $K_m$ and $K_n$, with some set of connections between them.

Denote the maximum clique $C_m \cup C_n$, where $C_m \subseteq K_m$, $C_n \subseteq K_n$, and call $M$ the remaining nodes in $K_m$.  These are the nodes we need to color in $|C_n|$ colors to show$ K_m \cup K_n$ is a weakly perfect graph.

Define the fanout $F(S)$ of a subset of $S \subseteq M$ as the set of nodes in $M$ that are NOT connected to $C_n$.  (This is an odd name, but it defines the set of colors $M$ can take).

\begin{lemma}[Expanding fanout lemma]
$|F(S)| \geq |S|$ for all $S \subseteq M.$
\end{lemma}

\emph{Proof:} Suppose that $|F(S)| < |S|$ for some $S \subseteq M$.  This means that $S$ is connected to all of $C_m$ (since $M \subset K_m$), and everything in $C_n$ except some set $F(S)$.  However, the clique $S \cup C_m \cap (C_n - F(S))$ is larger than $C_m \cap C_n$ since $|F(S)| < |S|$, which contradicts the maximality of $C_m \cap C_n$.

This also implies that $|F(M)| \geq |M|$, so $|C_n| \geq |M|$.

\begin{lemma}[Fanout colorability lemma]
 For every such $S \subseteq M$ with fanout $F(S)$ where $|F(S)| \geq |S|$, $S$ can be colored with the colors of $F(S)$.
\end{lemma}

We proceed by induction.  

Base case: If $|S| = 1$, then there is at least one node in $C_n$ unconnected to $S$, and we color it trivially.

Inductive step: 
The inductive step will be by contradiction.  Suppose this is true for all $|S| < k$ but NOT true for $|S| = k$.  First, if there is a subset of $T$ of $S$ where $|T| = |F(T)|$, then $|F(S-T)| \geq |S-T|$, and we have two smaller sets we can color separately by inductive hypothesis.  Thus, we assume $|F(T)| > |T|$ for all $T \subset S$.

If $T$ and $S-T$ both have fanouts larger than they, then they have to intersect in some node $X \in F(S)$.  Color this node in $T$ the color of the corresponding node in $C_n$ (remember, they are the ones NOT connected to $C_n$) and remove it from $T$ and $S-T$.  These reduced sets are colorable by inductive hypothesis. 

Therefore, $M$ can be colored with the colors of $C_n$,  and by symmetry, $N$ can be colored with the colors of $C_m$.

\textbf{Lovasz:} Say a graph is perfect and colorable in $k$ colors.  This is actually a $k$-partite graph, where each partition corresponds to one of the $k$ colors.  Its complement has cliques $K_1 ... K_k$ with some maximal clique among them.

The logic of the cobipartite graph applies completely; when discussing some $M$ excluded from the maximal clique, it did not matter how $C_n$ was distributed among other partitions.  In a bipartite graph, they were all in a second partition, but in a $k$-partite graph, they could just as easily be spread among $k-1$ partitions.  So each excluded subset $M_i$ of a partition can be colored with the colors of its fanout (among all $K_j, j \neq i$), no matter where they are grouped, and we have a  perfect graph.  We can say that a weakly perfect graph has a weakly perfect complement and by the Expanding Fanout Lemma, which will hold on every induced subgraph, a strongly perfect graph has a strongly perfect complement.


\section{Turan's Theorem Original Proof}

Define:
\[
  f(n,k)=\frac12\,n^{2}\Bigl(1-\frac1k\Bigr).
\]

\subsection*{Turan's theorem}

\begin{theorem}[Turan]
If a graph \(G=(V,E)\) on \(n\) nodes satisfies \(|E|>f(n,k)\), then \(G\) contains a \((k+1)\)-clique.
\end{theorem}

\paragraph{Contrapositive.}
If \(G\) has no \((k+1)\)-clique, then
\[
  |E|\le f(n,k).
\]

\bigskip
\textbf{Proof Plan}: If we can transform any graph  \(G=(V,E)\)  without a \((k+1)\)-clique into a graph  \(G^*=(V,E^*)\) where \(G^*\) has no  \((k+1)\)-clique and \(|E| = |E^*| \leq f(n,k)\), the contrapositive of Turan's theorem follows directly.

We consider such a set of graphs next: \(k\)-partite graphs.  An example of these is bipartite graphs ($k=2$).


\begin{lemma}[\(k\)-partite bound]\label{lem:kpartite}

A \(k\)-partite graph on \(n\) nodes contains no \((k+1)\)-clique and satisfies
\[
  |E|\le f(n,k).
\]
(The proof of the \(k\)-partite bound lemma is in a later section.)
\end{lemma}


\begin{lemma}[Transformation lemma]\label{lem:transform}
Let \(G\) be a graph on \(n\) nodes with no \((k+1)\)-clique.  
Then there exists a \(k\)-partite graph on the same node set with the same number of edges, in particular:
\[
  |E|\le\frac12 n^{2}\Bigl(1-\frac1k\Bigr),
\]
Additionally, \(G\) possesses a node of degree at most \(n\bigl(1-\frac1k\bigr)\).
\end{lemma}

\subsection*{Base case}
For \(n\le k+1\) the claim is immediate: the complete graph \(K_{k+1}\) contains \(\frac12(k+1)k\) edges.  If we have less than or equal to \(\frac12(k+1)k - 1\) edges, we cannot form a \(k+1\)-clique.  We show that this edge count is less than the bound.

\begin{align}
-\frac1{2}k^2-\frac{k}{2} + \frac1{2} \leq 0  \\
\frac1{2}k^3+\frac1{2}k^2-k \leq \frac1{2}k^3+k^2-\frac1{2}k-\frac1{2} \\
\frac1{2}k^3+\frac1{2}k^2-k \leq \frac1{2}(k^2+2k+1)(k-1) \\
\frac1{2}(k+1)k - 1 \leq \frac1{2}(k+1)^2\frac{k-1}{k} 
\end{align}


(1) is clear since $k > 1$.

Then, any graph avoiding a \((k+1)\)-clique already satisfies the bound and is itself \(k\)-partite (some parts may be empty).


Because \(|E| \leq \frac12 n^{2}(1-\frac1k)\), the average degree is at most \(n(1-\frac1k)\); hence some node has degree at most \(\lfloor(n(1-\frac1k)\rfloor\).

\subsection*{Inductive step}

Assume \(n>k+1\) and that the lemma holds for all  graph of node count \(n\) or fewer.  
Let \(G\) be a graph on \(n+1\) nodes with no \((k+1)\)-clique.

Every induced subgraph of size \(n\) also avoids \((k+1)\)-cliques and so meets the edge bound \(f(n,k)\).

\bigskip
\textbf{Goal:} find a node \(v\) of degree
\[
  \deg(v)\le D:=n-\left\lfloor\frac{n}{k}\right\rfloor.
\]

If so, we apply the induction hypothesis to \(G-v\) to obtain a \(k\)-partite graph, then assign \(v\) to a smallest partition (necessarily of size \(\leq \lfloor\frac{n}{k}\rfloor\)), rewiring its at most \(D\) edges across the remaining partitions.  The resulting graph is \(k\)-partite with the same edge count as \(G\).

\begin{lemma}[Degree bound lemma]\label{lem:degbound}

The above-mentioned bound \(\lfloor n(1-\frac1{k})\rfloor\) is equal to the bound target bound \(D\) if \(k\mid n\) and equal to \(D-1\) if \(k\nmid n\).

\end{lemma}

If \(k\mid n\) then
\[
 n-\Bigl\lfloor\frac{n}{k}\Bigr\rfloor=\Bigl\lfloor n\Bigl(1-\frac1k\Bigr)\Bigr\rfloor,
\]
 the floor operation becomes the identity and equality follows.
 
If \(n = qk + r, \lfloor n(1-\frac1{k})\rfloor = \lfloor(qk+r) - q - \frac{r}{k}\rfloor\), and \(n-\lfloor \frac{n}{k}\rfloor\) = \(qk+r-\lfloor(q+\frac{r}{k})\rfloor\).

Taking out the integer \(qk+r, \lfloor -q - \frac{r}{k}\rfloor < -\lfloor q + r/k\rfloor\), and they lie on either side of integer \(-q\), so \(\lfloor n(1-\frac1{k})\rfloor = 
n- \lfloor \frac{n}{k}\rfloor  - 1\).

\subsection*{Existence of a small degree node}

\begin{itemize}
\item If \(k\nmid n\), choose any subset of \(n\) nodes of \(G\), excluding some node $v$,

  By induction the subset contains a node \(w\) of degree \(\le n(1-\frac1k)\), which is  \(\leq D - 1\) by the Degree Bound Lemma, so the whole graph has such a node.  Even if \( (v, w) \in E\), \(w\) satisfies the degree bound.

\item Suppose now \(k\mid n\) (no more floors!) and, toward contradiction, that every node satisfies \(\deg(v) \geq D+1\).

  Count edges in all \(\binom{n+1}{n}=n+1\) induced \(n\)-node subgraphs.  
  By induction each has at most
  \[
    f(n,k)=\frac12 n^{2}\Bigl(1-\frac1k\Bigr)
  \]
  edges.  Summing and dividing by the multiplicity \(n-1\) with which each edge is counted (two subgraphs will contain its endpoints), we obtain an upper bound
  \[
    T_{\text{upper}}=\frac{n+1}{n-1}f(n,k).
  \]

  On the other hand, our degree assumption forces at least
  \[
    T_{\text{lower}}=\frac{n+1}{2}\bigl(n-\tfrac{n}{k}+1\bigr)
  \]
  edges in total.  Compute
  \[
    T_{\text{lower}}-T_{\text{upper}}
    =\frac{n+1}{2}\,\frac{n-k}{k(n-1)}>0
  \]
  because \(n>k\).  This contradiction establishes that a node of degree \(\le D\) exists.
\end{itemize}

\subsection*{Completion of the inductive step}

Removing the low-degree node and applying the rewiring argument yields a \(k\)-partite graph on \(n+1\) nodes with the same edge count as \(G\).  
Hence every \((n+1)\)-node graph without a \((k+1)\)-clique satisfies
\[
  |E|\le\frac12 n^{2}\Bigl(1-\frac1k\Bigr).
\]

\bigskip
\noindent
\textbf{Corollary (Turan).}\;
If \(|E|>\frac12 n^{2}(1-\frac1k)\) then \(G\) must contain a \((k+1)\)-clique.


\subsection*{Proof of k-partite lemma}

A \(k\)-partite graph has \(k\) partitions of nodes, within which all are disconnected.  The nodes from differing partitions may connect.  Clearly, a $k+1$-clique cannot exist among them, as nodes within each partition are disconnected, and there are only $k$ partitions. 

A perfectly balanced graph has partitions all of equal size.

\begin{proposition}
The edge-count formula of a perfectly balanced $k$-partite graph is
\[
E_p(n,k)=\frac{n^{2}}{2}\Bigl(1-\frac{1}{k}\Bigr).
\]
\end{proposition}

Each of \(n\) nodes connects to \(n\frac{k-1}{k}\) nodes in other partitions.  We divide by two to get the number of edges.

\begin{proposition}
The edge-count formula of a perfectly balanced graph of node total $n$ is the upper bound to any partitioning of nodes among $k$ partitions.
\end{proposition}

We are looking at maximizing $f(\vec{a}) = \frac1{2}\sum_{i \neq j; i, j < k}^k a_i a_j$, where $a_i$ is the node count of partition $i$.

We can write this as 
\begin{align}
f(\vec{a}) = \frac1{2}\sum_{i \neq j; i, j < k} a_i a_j =  (\sum_i^k a_i)^2-  \frac1{2} \sum_i^k{a_i}^2  = n^2-  \frac1{2} \sum_i^k{a_i}^2 
\end{align}

 So we are looking at minimizing the final term to maximize $f(\vec{a})$

Consider the definition of statistical variance: 
\begin{align}
Var(a_1, a_2 ... a_k) = \sum_{i=1}^k (a_i - \bar{a})^2 =  \sum_{i=1}^k (a_i^2 - 2\bar{a}a_i+\bar{a}^2) 
\end{align}

So $Var(a_1, a_2 ... a_k) = \frac1{k}[\sum_{i=1}^k (a_i^2) - 2\bar{a}(\sum_{i=1}^k a_i) + k\bar{a}^2]$

Note that $2\bar{a}(\sum_{i=1}^k a_i) = 2k\bar{a}^2$.

Thus, ignoring constant terms, minimizing $Var(a_1, a_2 ... a_k)$ is the same as minimizing  $\sum_{i=1}^k{a_i}^2$.  But the variance reaches its minimum at zero when all values $a_i$ are equal.  This is therefore bounded by the edge count of the equal partition $E_p(n,k)=\frac{n^{2}}{2}\Bigl(1-\frac{1}{k}\Bigr).$

\subsection*{Conclusion}
Therefore, any $k$-partite graph has less than or equal to $\frac{n^{2}}{2}\Bigl(1-\frac{1}{k}\Bigr)$ edges.
