\begin{theorem}The expected chance of a perfect game with $r$ standard dice of $s$ sides each,  given $p := \frac1{s}$, is $P(r) = \Sigma_{k=1}^r {r \choose k} p^k q^{r-k} P(r-k)$, with $P(0)$ defined as 1.
\end{theorem}
\textit{Proof}: This a clear application of the binomial theorem.  

Bounding this quantity will be the principal thrust of this paper.

\begin{lemma}[Easy Cases Lemma] If $p = 0$, P(r) = 0.  If $p = 1, P(r) = 1$. If $s = 2$, for any $r > 0,P(r) = \frac{1}{2}$.
\end{lemma}
\textit{Proof}: 
Though we won't be flipping infinite $(p=0)$ or 1-sided $(p=1)$, dice, these algebraic identities are obvious (can't succeed, can't fail, respectively) and will be useful later.

\textbf{Base case for s=2}: $P(1) = \frac1{2}$ since a perfect game occurs if and only if the coin flips 2 instead of 1.

\textbf{Inductive case for s=2}: Assuming $P(k) = \frac1{2}$ for all $0 < k < r$,  and $P(0) = 1$:
\begin{align}
\Sigma_{k=1}^{r-1} {r \choose k} p^k q^{r-k} P(r-k) + {r \choose r} p^r q^0 P(0) = \\
 (2^r - 2) \frac1{2^r} (\frac1{2}) + \frac1{2^r} 2(\frac1{2}) = \\
 (2^r) \frac1{2^r} (\frac1{2}) = \frac1{2}
\end{align}

\begin{theorem}For an unbounded set of $r > 0$ standard $s$-sided dice, $s \geq 2$, the probability $P(r)$ of getting a perfect game has a lower bound of $\exp(-\frac{q}{(1-q)^2})$, if we define  $q := 1-\frac1{s}$.
\end{theorem}
\textit{Proof}:

\begin{itemize}
\item First, while at stage $k$, where $k$ dice remain, the probabilty $P_{s}(k)$ of continuing to some stage $j < k$  is clearly $1 - q^k$.
\item The probability $P(k)$ of passing all such stages is greater than or equal to $P^* = \Pi_{i=1}^k P_{s}(k)$, since a successful traversal may involve skipping one or more stages, and $P^*$ assumes we no stages.

\item Therefore, $P(k) \geq \Pi_{i=1}^k P_{s}(k) =  \Pi_{i=1}^k (1-q^k)$.
\item This means $\log(P(k)) \geq \Sigma_{i=1}^k \log(P_{s}(k)) = \Sigma_{i=1}^k \log(1-q^k)$.
\end{itemize}

This $P(k)$ is apparently defined as the \textbf{q-Pochhammer symbol} $(q;q)_\infty = \Pi_{i=1}^k (1-q^k)$, with known convergence properties.  I'll instead attempt to tackle convergence without the aid of these theorems.

Often, $\log(1-z)$ is approximated by $-z$ near zero, but we are most concerned with $z$ near one, since $1-z$ approaches 0, and $\log(1-z)$ explodes.  Therefore, let's look at the expansion of $\log(1-z)$:
\begin{itemize}
\item Identity 1: $f(z) = -\frac1{1-z} = - 1 - z - z^2 -  \ldots$
\item Identity 2: $\int f(z) = \log(1-z) = -z-\frac{z^2}{2} - \frac{z^3}{3} - \ldots$
\end{itemize}

So when summing $\Sigma_{i=1}^k \log(1-q^k)$, we can instead sum 
\begin{align}
\log(P(k)) = \log(1-q^1) + \log(1-q^2) + \log(1-q^3) + \ldots \\ 
\log(P(k)) = (-q - \frac{q^2}{2} - \frac{q^3}{3} + \ldots) +  (-q^2 - \frac{q^4}{2} - \frac{q^6}{3} + \ldots) +  (-q^3 - \frac{q^6}{2} - \frac{q^9}{3} + \ldots) +  \ldots \\
> (-q - q^2 - q^3 + \ldots) +   (-q^2 - q^4 - q^6 + \ldots) +  (-q^3 - q^6 - q^9 + \ldots) + \ldots \\
= \frac{-q}{1-q} + \frac{-q^2}{1-q^2} + \frac{-q^3}{1-q^3} +    \ldots \\
> \frac{-q}{1-q} + \frac{-q^2}{1-q} + \frac{-q^3}{1-q} +    \ldots \\
= \frac1{1-q}[-q -q^2 - q^3 - \ldots ]\\
= \frac{-q}{(1-q)^2} 
\end{align}

\begin{itemize}
\item (2) follows from (1) by substitution using Identity1 above.
\item (3) follows from (2) since the denominators of (2) are larger.
\item (4) follows from (3) when dividing each sequence by $-q^k$  and applying identity 2.
\item (5) follows from (4) since the denominators of (4) are larger.
\item (6) and (7) follow from (5) by dividing out $\frac1{1-q}$ and applying Identity 1.
\end{itemize}

Since $\log(P(k))  > \frac{-q}{(1-q)^2}$, $P(k) > \exp (\frac{-q}{(1-q)^2)})$.

However, this does provide a positive lower bound, and brings up this interesting fact: \textbf{Though increasing the number of sides of the dice can drive P(k) to zero, increasing k to $\infty$ will never set P(k) to zero}.
